# Zomato-Sales-Analysis-PowerBI
"A Power BI dashboard analyzing Zomato sales trends from 2017 to 2020"

Zomato Sales Insights Dashboard

Project Overview
  This project analyzes Zomato's delivery data to identify sales trends and     popular food categories.

Key Features
  * Total Revenue: $987M.
  * Top Cities: Insights into high-performing regions like Tirupati.
  
  
Category Analysis:
  Breakdown of Veg ($122M) vs Non-Veg ($106M) sales.
  
  
Tech Stack
  * Tool: Microsoft Power BI.
  * Data Source: Zomato historical order data
